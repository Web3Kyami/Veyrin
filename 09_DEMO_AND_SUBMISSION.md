## 6-part project description — template (fill actual evidence)
1. **Thesis:** "The market judges trades in hindsight, and generic LLM summaries can retroactively rationalize moves. VEYRIN makes three specialized AI research passes work from a cut-off source packet, preserving a verifiable pre-reveal record before comparing it with observed reactions." Make distinction from actual historical forecast explicit.
2. **Target user & value:** Self-directed active tokenized-US-equity / U.S.-stock traders examining earnings or market events, especially outside NYSE hours. User wants uncertainty-aware evidence and a reusable research checklist, not a blind buy/sell call.
3. **Validation & metrics:** Only measured figures: e.g. number of verified source records, role completion rate, result latency, real Bitget queries, coverage of compared observations, manual reviewer test if conducted. Mark planned metrics targeted. Do not assert users/returns not observed.
4. **Progress:** Working flows, exact Bitget tool integration used, LLM model ID if appropriate, verified case count, known missing data/limitations, upcoming improvements. If limited to one curated case, say so openly.
5. **Deliverables:** Public Vercel no-login demo, GitHub repo (correct licence), public README, short video, evidence manifest/sealed transcript, reproducibility scripts, proof page, official source links.
6. **Your take on AI Trading (optional):** AI research should be stress-tested against dated evidence and opposing hypotheses; distinguish retrospective rationalization from forward research.
