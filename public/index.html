Source time

Four linked pre-event sources preserve their displayed timestamp precision. A displayed date is not upgraded to a fabricated clock time. The server rejects unknown source IDs and post-cutoff evidence.

Bitget identity

The comparison uses Bitget’s NVDA Reality stock token, quoted in USDT. Both observations are completed 15-minute candles from the same instrument. Identity, time window and quote currency are checked before use.

Role outputs

ATLAS, VEX and SEAL are three specialized reasoning passes using one configured model. Each response is checked for required evidence and valid citations.

A signed digest locks the exact source packet and role outputs. The market window can open only after that record verifies.

KNOWN LIMITS

Read the result at the right scale.

  • Historical reconstruction can never prove an LLM did not learn the outcome during training.
  • One model used in three roles is not three independent model providers.
  • Two selected 15-minute candles are not a continuous chart and do not establish causality.
  • The server signature depends on a configured signing key; changing the signing key invalidates older receipt signatures.
  • Download your receipt to keep it. This browser session has no permanent shared link.
  • No orders, wallet connection, user funds, investment advice or claimed return are involved.
