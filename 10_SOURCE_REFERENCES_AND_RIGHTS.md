## Rights and sourcing protocol
- `git clone` public repo for *local study* okay subject to site/platform terms. Public visibility is not blanket license to redistribute derivative artwork/code.
- If borrowed code is necessary, require explicit valid license and file notices, keep attribution and assess restrictions; otherwise reimplement independently. For original illustration, retain generator prompts/commission terms/source provenance and ensure commercial rights.
- For external price data, obey API vendor usage and caching conditions; do not redistribute large historical series without license. Display verified links and necessary concise excerpts only.
- No logos imply partnership beyond hackathon participation. Bitget brand references should comply with their published guidelines.

## Competitive positioning, not copy
CROSSFIRE proves adversarial visual theater can make technical agent systems understandable; NightDesk proves risk gates and real data; Nocturne proves honesty matters. VEYRIN must stand on a distinct user job: **cutoff-constrained evidence trial and hindsight-bias learning**. It has no capped money stakes, no sports market, no simulated profitable trading, and no multi-agent voting façade.
